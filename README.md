###### Description ###### 

This projects retrieves 50 books information from OpenLibrary API. Filters and sorts books published after 2000s. Saves them in CSV file.





###### Requirements ###### 

python

requests



###### Installation ###### 

pip install requests



###### Output ###### 

books\_in\_order.csv
